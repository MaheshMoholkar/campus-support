# Milestone 1 Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A complete, tested HTTP API for the Campus Support ticket lifecycle (no AI): login, five roles, tickets, the transition table, timeline events, timer, attachments, register filters, dashboard, admin master data, seed data and CI.

**Architecture:** FastAPI app in `backend/` with three layers: routers (HTTP only), services (rules), SQLAlchemy models. Every status change goes through one transition table. Every change to a ticket writes an append-only `ticket_events` row. Tests run against real Postgres inside a transaction that is rolled back after each test.

**Tech Stack:** Python 3.14, FastAPI, SQLAlchemy 2 (sync) with psycopg 3, Alembic, Pydantic 2, argon2-cffi, PyJWT, boto3, pytest, ruff, pyright, uv. Postgres 17 with pgvector and Garage (S3) from the homelab.

**Spec:** `docs/specs/2026-09-30-campus-support-design.md`

**Scope note:** Milestone 1 is split into two plans. This one delivers the backend. The frontend plan (`docs/plans/2026-09-30-m1-frontend.md`) is written after this one is executed, because its TypeScript types are generated from this API's OpenAPI document.

## Global Constraints

- Python 3.14, pinned in `backend/.python-version`. If a dependency has no 3.14 build, pin 3.13 instead (Task 1, Step 2) and use 3.13 everywhere this plan says 3.14.
- Sync SQLAlchemy, not async. FastAPI runs sync routes in a thread pool; sync code is simpler to test and debug.
- Layers: routers contain no queries. The only database call a router makes is `db.commit()` after a service call succeeds. Services call `db.flush()`, never `db.commit()`.
- All status changes go through `TRANSITIONS` in `app/services/transitions.py`. No other code assigns `ticket.status`.
- `ticket_events` is append-only: no code updates or deletes a row.
- Each user has exactly one role: `reporter`, `approver`, `lead`, `developer`, `admin`.
- Ticket number format: `CS-000123`, from the Postgres sequence `ticket_number_seq`.
- Session: signed token in an httpOnly, SameSite=Lax cookie named `cs_session`, 12-hour expiry. No self-registration.
- Attachments: 10 MB per file, 5 files per ticket or message; images, PDF and common office formats.
- Enum columns are stored as plain `VARCHAR` holding the enum value, so adding a value later needs no schema change.
- The app reads configuration only from environment variables (`.env.lab` from `lab up`, or real env in CI). `.env.lab` and `.env` are never committed.
- All data is invented. Seed emails use `@tarangini.example`; phone numbers start with `00000`. Nothing is copied from the screenshots of the old system.
- All routes are under `/api/v1`.
- Work happens on the branch `m1-backend`. Each task ends with one commit; the executor appends the session's `Co-Authored-By` trailer to each commit message.
- After each task: `uv run ruff check . && uv run ruff format --check . && uv run pyright && uv run pytest -q` must pass in `backend/`.

## Review Focus

Conditions the spec implies but does not spell out. Each has a test in the task named.

1. **Right role, wrong relationship.** A developer who is not the assignee calls `start` or `close`; an approver of another section calls `approve`. Expected: 403 from the transition table, ticket unchanged. Over HTTP the approver of another section cannot see the ticket at all, so the response is 404. (Task 4 `FORBIDDEN` table, Task 6 `test_wrong_relationship_is_403`)
2. **Null approval section.** Internal tickets have no section, and an approver account may have none. Expected: an approver never sees or acts on an internal ticket, and `NULL = NULL` never counts as a match. (Task 4 `FORBIDDEN` table, Task 5 `test_approver_without_section_sees_nothing`)
3. **Timer across side statuses.** A ticket goes In Process → Clarification Required → reply → In Process. Expected: the timer stopped on the way out and does not restart by itself; time spent counts only the running segments. (Task 5 `test_side_status_loop_from_in_process`)
4. **Actions on a final ticket, or the same action twice.** Close a closed ticket, start a started ticket, pause twice, message on a closed ticket. Expected: 409 with a clear message, never a 500. (Task 4 `NOT_ALLOWED` table, Task 5 `test_timer_conflicts`, `test_no_messages_on_final_ticket`)
5. **Attachment keys that are not yours or not there.** A key uploaded by another user, a key never uploaded, a file over 10 MB, a key already attached. Expected: 422, nothing recorded. (Task 7 `test_attach_rejects_bad_keys`)

```python
from pathlib import Path

from pydantic_settings import BaseSettings, SettingsConfigDict

REPO_ROOT = Path(__file__).resolve().parents[3]


class Settings(BaseSettings):
    """Configuration from environment variables; `.env.lab` is written by `lab up`."""

    model_config = SettingsConfigDict(
        env_file=(REPO_ROOT / ".env.lab", REPO_ROOT / "backend" / ".env"),
        extra="ignore",
    )

    database_url: str
    session_secret: str = "dev-only-secret-change-me-0123456789abcdef"
    session_hours: int = 12
    cookie_secure: bool = False

    @property
    def sqlalchemy_url(self) -> str:
        # SQLAlchemy needs the driver in the scheme; `.env.lab` gives the plain form.
        for prefix in ("postgresql://", "postgres://"):
            if self.database_url.startswith(prefix):
                return "postgresql+psycopg://" + self.database_url[len(prefix) :]
        return self.database_url


settings = Settings()  # pyright: ignore[reportCallIssue]
```

```python
from sqlalchemy import Enum as SAEnum
from sqlalchemy.orm import DeclarativeBase


class Base(DeclarativeBase):

def utcnow() -> datetime:
    return datetime.now(UTC)


def str_enum(enum_cls: type[StrEnum]) -> SAEnum:
    """Map a StrEnum to a plain VARCHAR column that stores the enum's value."""
    return SAEnum(
        enum_cls,
        native_enum=False,
        length=40,
        values_callable=lambda cls: [member.value for member in cls],
        validate_strings=True,
    )
```

- [ ] **Step 3: Alembic setup**

Alembic is the equivalent of EF Core migrations: versioned scripts, generated by comparing the models with the database.

```bash
cd backend
uv run alembic init alembic
```

Replace `backend/alembic/env.py` with:

```python
from alembic import context
from sqlalchemy import Connection, create_engine, pool

from app.core.config import settings
from app.models import Base

config = context.config
target_metadata = Base.metadata


def run_migrations(connection: Connection) -> None:
    context.configure(
        connection=connection,
        target_metadata=target_metadata,
        # Tests keep their own version table. Without this, Alembic finds the
        # development one through the search path and migrates nothing.
        version_table_schema=config.attributes.get("version_table_schema"),
    )
    with context.begin_transaction():
        context.run_migrations()


# Tests pass their own connection (schema `test`); the CLI connects from settings.
supplied = config.attributes.get("connection")
if supplied is not None:
    run_migrations(supplied)
else:
    engine = create_engine(settings.sqlalchemy_url, poolclass=pool.NullPool)
    with engine.connect() as connection:
        run_migrations(connection)
```

```python
from datetime import UTC, datetime, timedelta

import jwt
from argon2 import PasswordHasher
from argon2.exceptions import InvalidHashError, VerificationError

from app.core.config import settings

COOKIE_NAME = "cs_session"
_ALGORITHM = "HS256"
_hasher = PasswordHasher()


def hash_password(password: str) -> str:
    return _hasher.hash(password)


def verify_password(password: str, password_hash: str) -> bool:
    try:
        return _hasher.verify(password_hash, password)
    except (VerificationError, InvalidHashError):
        return False


def create_session_token(user_id: int, now: datetime | None = None) -> str:
    issued = now or datetime.now(UTC)
    payload = {
        "sub": str(user_id),
        "iat": issued,
        "exp": issued + timedelta(hours=settings.session_hours),
    }
    return jwt.encode(payload, settings.session_secret, algorithm=_ALGORITHM)


def read_session_token(token: str) -> int | None:
    """Return the user id, or None if the token is invalid or expired."""
    try:
        payload = jwt.decode(token, settings.session_secret, algorithms=[_ALGORITHM])
        return int(payload["sub"])
    except (jwt.PyJWTError, KeyError, ValueError):
        return None
```

```python
from collections.abc import Callable, Iterator
from typing import Annotated

from fastapi import Cookie, Depends, HTTPException
from sqlalchemy.orm import Session

from app.core.db import SessionLocal
from app.core.enums import Role
from app.core.security import read_session_token
from app.models import User


def get_db() -> Iterator[Session]:
    session = SessionLocal()
    try:
        yield session
    except Exception:
        session.rollback()
        raise
    finally:
        session.close()


DbDep = Annotated[Session, Depends(get_db)]


def current_user(db: DbDep, cs_session: Annotated[str | None, Cookie()] = None) -> User:
    user_id = read_session_token(cs_session) if cs_session else None
    user = db.get(User, user_id) if user_id is not None else None
    if user is None or not user.is_active:
        raise HTTPException(status_code=401, detail="Not authenticated")
    return user


CurrentUser = Annotated[User, Depends(current_user)]


def require_roles(*roles: Role) -> Callable[[User], User]:
    def checker(user: CurrentUser) -> User:
        if user.role not in roles:
            raise HTTPException(status_code=403, detail="Not allowed for your role")
        return user

    return checker
```

```python
from app.core.security import hash_password, verify_password
from app.models import User

# Verified when the email is unknown, so both failure paths take similar time.
_DUMMY_HASH = hash_password("no-such-user")


def normalise_email(email: str) -> str:
    return email.strip().lower()


def authenticate(db: Session, email: str, password: str) -> User | None:
    user = db.execute(
        select(User).where(User.email == normalise_email(email))
    ).scalar_one_or_none()
    if user is None:
        verify_password(password, _DUMMY_HASH)
        return None
    if not verify_password(password, user.password_hash) or not user.is_active:
        return None
    return user
```

```python
    assignee_id: int | None
    approval_section_id: int | None


Guard = Callable[[Actor, TicketState], bool]


def is_section_approver(actor: Actor, ticket: TicketState) -> bool:
    return (
        actor.role is Role.APPROVER
        and ticket.approval_section_id is not None
        and actor.approval_section_id == ticket.approval_section_id
    )


def is_lead(actor: Actor, ticket: TicketState) -> bool:
    return actor.role is Role.LEAD


def is_assignee(actor: Actor, ticket: TicketState) -> bool:
    return ticket.assignee_id is not None and actor.id == ticket.assignee_id


def is_reporter(actor: Actor, ticket: TicketState) -> bool:
    return actor.id == ticket.reporter_id


def any_of(*guards: Guard) -> Guard:
    return lambda actor, ticket: any(guard(actor, ticket) for guard in guards)


class Target(Enum):
    SAME = "same"  # status does not change
    SIDE = "side"  # one of the three side statuses, chosen by the caller
    PREVIOUS = "previous"  # the status the ticket came from


@dataclass(frozen=True)
class Rule:
    guard: Guard
    target: Status | Target


_PENDING = Status.PENDING_APPROVAL
_QUEUE = Status.WAITING_IN_QUEUE
_IN_PROCESS = Status.IN_PROCESS

TRANSITIONS: dict[tuple[Status, Action], Rule] = {
    (_PENDING, Action.APPROVE): Rule(is_section_approver, _QUEUE),
    (_PENDING, Action.REJECT): Rule(is_section_approver, Status.REJECTED),
    (_PENDING, Action.REQUEST_INFO): Rule(is_section_approver, Target.SIDE),
    (_QUEUE, Action.ASSIGN): Rule(is_lead, Target.SAME),
    (_QUEUE, Action.SET_ESTIMATE): Rule(is_lead, Target.SAME),
    (_QUEUE, Action.REQUEST_INFO): Rule(any_of(is_lead, is_assignee), Target.SIDE),
    (_QUEUE, Action.START): Rule(is_assignee, _IN_PROCESS),
    (_IN_PROCESS, Action.PAUSE): Rule(is_assignee, Target.SAME),
    (_IN_PROCESS, Action.RESUME): Rule(is_assignee, Target.SAME),
    (_IN_PROCESS, Action.SET_ESTIMATE): Rule(is_lead, Target.SAME),
    (_IN_PROCESS, Action.REQUEST_INFO): Rule(is_assignee, Target.SIDE),
    (_IN_PROCESS, Action.ASSIGN): Rule(is_lead, _QUEUE),
    (_IN_PROCESS, Action.CLOSE): Rule(is_assignee, Status.CLOSED),
    **{(side, Action.REPLY): Rule(is_reporter, Target.PREVIOUS) for side in SIDE_STATUSES},
}


def resolve(
    actor: Actor, ticket: TicketState, action: Action, side_status: Status | None = None
) -> Status:
    """Return the status the ticket moves to, or raise if the action is not allowed."""
    rule = TRANSITIONS.get((ticket.status, action))
    if rule is None:
        raise Conflict(f"Cannot {action.value} a ticket that is {ticket.status.value}")
    if not rule.guard(actor, ticket):
        raise Forbidden("You are not allowed to do this on this ticket")
    if rule.target is Target.SAME:
        return ticket.status
    if rule.target is Target.SIDE:
        if side_status is None or side_status not in SIDE_STATUSES:
            raise Invalid(
                "side_status must be clarification_required, insufficient_data "
                "or poor_quality_images"
            )
        return side_status
    if rule.target is Target.PREVIOUS:
        if ticket.previous_status is None:
            raise Conflict("Ticket has no status to return to")
        return ticket.previous_status
    assert isinstance(rule.target, Status)
    return rule.target


def allowed_actions(actor: Actor, ticket: TicketState) -> list[Action]:
    return [
        action
        for (status, action), rule in TRANSITIONS.items()
        if status is ticket.status and rule.guard(actor, ticket)
    ]
```

```python
from sqlalchemy import select
from sqlalchemy.orm import Session

from app.core.errors import Conflict
from app.models import WorkSession


def open_session(db: Session, ticket_id: int) -> WorkSession | None:
    return db.execute(
        select(WorkSession).where(
            WorkSession.ticket_id == ticket_id, WorkSession.stopped_at.is_(None)
        )
    ).scalar_one_or_none()


def start_timer(db: Session, ticket_id: int, developer_id: int, now: datetime) -> WorkSession:
    if open_session(db, ticket_id) is not None:
        raise Conflict("Timer is already running")
    session = WorkSession(ticket_id=ticket_id, developer_id=developer_id, started_at=now)
    db.add(session)
    db.flush()
    return session


def stop_timer(db: Session, ticket_id: int, now: datetime) -> bool:
    """Close the open segment. Returns False if the timer was not running."""
    session = open_session(db, ticket_id)
    if session is None:
        return False
    session.stopped_at = max(now, session.started_at)
    db.flush()
    return True


def seconds_spent(db: Session, ticket_id: int, now: datetime) -> int:
    sessions = db.scalars(select(WorkSession).where(WorkSession.ticket_id == ticket_id))
    return int(sum(((s.stopped_at or now) - s.started_at).total_seconds() for s in sessions))
```

```python
from datetime import UTC, datetime

from sqlalchemy import false, func, select
from sqlalchemy.orm import Session, selectinload

from app.core.enums import FINAL_STATUSES, SIDE_STATUSES, Action, EventType, Role, Source, Status
from app.core.errors import Conflict, Forbidden, Invalid, NotFound
from app.models import ApprovalSection, ErpModule, Ticket, TicketEvent, User, ticket_number_seq
from app.schemas.tickets import (
    ActionBody,

    TicketOut,

from app.services import timer
from app.services.transitions import Actor, TicketState, allowed_actions, resolve

REMARK_REQUIRED = frozenset(
    {Action.APPROVE, Action.REJECT, Action.REQUEST_INFO, Action.REPLY, Action.CLOSE}
)


def _now() -> datetime:
    return datetime.now(UTC)


def _actor(user: User) -> Actor:
    return Actor(user.id, user.role, user.approval_section_id)


def _state(ticket: Ticket) -> TicketState:
    return TicketState(
        ticket.status,
        ticket.previous_status,
        ticket.reporter_id,
        ticket.assignee_id,
        ticket.approval_section_id,
    )


def _record(
    db: Session,
    ticket: Ticket,
    actor: User,
    event_type: EventType,
    now: datetime,
    *,
    from_value: str | None = None,
    to_value: str | None = None,
    body: str | None = None,
    suggested_by: str | None = None,
) -> TicketEvent:
    event = TicketEvent(
        ticket_id=ticket.id,
        actor_id=actor.id,
        event_type=event_type,
        from_value=from_value,
        to_value=to_value,
        body=body,
        suggested_by=suggested_by,
        created_at=now,
    )
    db.add(event)
    return event


def can_view(actor: User, ticket: Ticket) -> bool:
    if actor.role is Role.REPORTER:
        return ticket.reporter_id == actor.id
    if actor.role is Role.APPROVER:
        return (
            ticket.approval_section_id is not None
            and ticket.approval_section_id == actor.approval_section_id
        )
    return True


def get_visible_ticket(
    db: Session, actor: User, ticket_id: int, *, lock: bool = False
) -> Ticket:
    """Load a ticket the actor may see. With lock=True the row is locked until commit,
    so two simultaneous actions on one ticket run one after the other."""
    stmt = select(Ticket).where(Ticket.id == ticket_id)
    if lock:
        stmt = stmt.with_for_update().execution_options(populate_existing=True)
    ticket = db.execute(stmt).scalar_one_or_none()
    if ticket is None or not can_view(actor, ticket):
        raise NotFound("Ticket not found")
    return ticket


def create_ticket(
    db: Session, actor: User, data: TicketCreate, source: Source, now: datetime | None = None
) -> Ticket:
    """The single entry point for new tickets. The source decides the entry status."""
    now = now or _now()
    if source is Source.INTERNAL:
        if actor.role not in (Role.DEVELOPER, Role.LEAD):
            raise Forbidden("Only developers and the lead can raise internal tickets")
        section_id = None
        status = Status.WAITING_IN_QUEUE
    else:
        if actor.role is not Role.REPORTER:
            raise Forbidden("Only reporters can raise tickets")
        if (
            data.approval_section_id is None
            or db.get(ApprovalSection, data.approval_section_id) is None
        ):
            raise Invalid("Choose a valid approval section")
        section_id = data.approval_section_id
        status = Status.PENDING_APPROVAL
    if data.erp_module_id is not None and db.get(ErpModule, data.erp_module_id) is None:
        raise Invalid("Unknown ERP module")

    seq = db.execute(select(ticket_number_seq.next_value())).scalar_one()
    ticket = Ticket(
        number=f"CS-{seq:06d}",
        source=source,
        reporter_id=actor.id,
        institute_id=actor.institute_id,
        approval_section_id=section_id,
        ticket_for=data.ticket_for,
        ticket_type=data.ticket_type,
        erp_module_id=data.erp_module_id,
        page_url=data.page_url,
        description=data.description,
        contact_number=data.contact_number,
        extension=data.extension,
        status=status,
        created_at=now,
        updated_at=now,
    )
    db.add(ticket)
    db.flush()
    _record(db, ticket, actor, EventType.CREATED, now, to_value=status.value)
    db.flush()
    return ticket


def _set_estimate(db: Session, actor: User, ticket: Ticket, minutes: int, now: datetime) -> None:
    if ticket.estimate_minutes == minutes:
        return
    old = ticket.estimate_minutes
    ticket.estimate_minutes = minutes
    _record(
        db,
        ticket,
        actor,
        EventType.ESTIMATE_CHANGE,
        now,
        from_value=None if old is None else str(old),
        to_value=str(minutes),
    )


def _assign(db: Session, actor: User, ticket: Ticket, body: ActionBody, now: datetime) -> None:
    developer = db.get(User, body.assignee_id) if body.assignee_id is not None else None
    if developer is None or developer.role is not Role.DEVELOPER or not developer.is_active:
        raise Invalid("assignee_id must be an active developer")
    previous = ticket.assignee_id
    if previous == developer.id:
        raise Conflict("Ticket is already assigned to this developer")
    ticket.assignee = developer
    _record(
        db,
        ticket,
        actor,
        EventType.ASSIGN if previous is None else EventType.REASSIGN,
        now,
        from_value=None if previous is None else str(previous),
        to_value=str(developer.id),
        suggested_by="lead",
    )
    if body.estimate_minutes is not None:
        _set_estimate(db, actor, ticket, body.estimate_minutes, now)


def apply_action(
    db: Session,
    actor: User,
    ticket_id: int,
    action: Action,
    body: ActionBody,
    now: datetime | None = None,
) -> Ticket:
    now = now or _now()
    ticket = get_visible_ticket(db, actor, ticket_id, lock=True)
    old_status = ticket.status
    new_status = resolve(_actor(actor), _state(ticket), action, body.side_status)
    if action in REMARK_REQUIRED and not body.remark:
        raise Invalid("A remark is required for this action")

    if action is Action.ASSIGN:
        _assign(db, actor, ticket, body, now)
    elif action is Action.SET_ESTIMATE:
        if body.estimate_minutes is None:
            raise Invalid("estimate_minutes is required")
        _set_estimate(db, actor, ticket, body.estimate_minutes, now)
    elif action in (Action.START, Action.RESUME):
        timer.start_timer(db, ticket.id, actor.id, now)
    elif action is Action.PAUSE:
        if not timer.stop_timer(db, ticket.id, now):
            raise Conflict("Timer is not running")

    if new_status != old_status:
        if old_status is Status.IN_PROCESS:
            timer.stop_timer(db, ticket.id, now)
        ticket.previous_status = old_status if new_status in SIDE_STATUSES else None
        if new_status is Status.CLOSED:
            ticket.closed_at = now
        ticket.status = new_status
        _record(
            db,
            ticket,
            actor,
            EventType.STATUS_CHANGE,
            now,
            from_value=old_status.value,
            to_value=new_status.value,
            body=body.remark,
        )
    ticket.updated_at = now
    db.flush()
    return ticket


def add_message(
    db: Session, actor: User, ticket_id: int, body: str, now: datetime | None = None
) -> TicketEvent:
    now = now or _now()
    ticket = get_visible_ticket(db, actor, ticket_id)
    if ticket.status in FINAL_STATUSES:
        raise Conflict("This ticket is closed; no more messages can be added")
    event = _record(db, ticket, actor, EventType.MESSAGE, now, body=body)
    ticket.updated_at = now
    db.flush()
    return event


def bulk_assign(
    db: Session,
    actor: User,
    ticket_ids: list[int],
    assignee_id: int,
    estimate_minutes: int | None = None,
    now: datetime | None = None,
) -> list[Ticket]:
    """Assign many tickets. Any failure raises, and the request's rollback undoes all."""
    body = ActionBody(assignee_id=assignee_id, estimate_minutes=estimate_minutes)
    result: list[Ticket] = []
    for ticket_id in sorted(set(ticket_ids)):  # fixed order, so row locks cannot deadlock
        ticket = get_visible_ticket(db, actor, ticket_id, lock=True)
        if ticket.assignee_id != assignee_id:
            ticket = apply_action(db, actor, ticket_id, Action.ASSIGN, body, now)
        result.append(ticket)
    return result


def list_tickets(db: Session, actor: User, filters: TicketFilters) -> tuple[list[Ticket], int]:
    stmt = select(Ticket)
    if actor.role is Role.REPORTER:
        stmt = stmt.where(Ticket.reporter_id == actor.id)
    elif actor.role is Role.APPROVER:
        if actor.approval_section_id is None:
            stmt = stmt.where(false())
        else:
            stmt = stmt.where(Ticket.approval_section_id == actor.approval_section_id)
    if filters.mine:
        owner = Ticket.assignee_id if actor.role is Role.DEVELOPER else Ticket.reporter_id
        stmt = stmt.where(owner == actor.id)
    for column, value in (
        (Ticket.institute_id, filters.institute_id),
        (Ticket.ticket_for, filters.ticket_for),
        (Ticket.ticket_type, filters.ticket_type),
        (Ticket.status, filters.status),
        (Ticket.assignee_id, filters.assignee_id),
    ):
        if value is not None:
            stmt = stmt.where(column == value)

    total = db.execute(select(func.count()).select_from(stmt.subquery())).scalar_one()
    rows = db.scalars(
        stmt.options(selectinload(Ticket.reporter), selectinload(Ticket.assignee))
        .order_by(Ticket.created_at.desc(), Ticket.id.desc())
        .limit(filters.limit)
        .offset(filters.offset)
    )
    return list(rows), total


def ticket_detail(
    db: Session, actor: User, ticket: Ticket, now: datetime | None = None
) -> TicketDetail:
    now = now or _now()
    db.flush()
    db.refresh(ticket)  # reload columns and relationships changed earlier in the request
    return TicketDetail(
        **TicketOut.model_validate(ticket).model_dump(),
        contact_number=ticket.contact_number,
        extension=ticket.extension,
        events=[EventOut.model_validate(event) for event in ticket.events],
        attachments=[AttachmentOut.model_validate(a) for a in ticket.attachments],
        seconds_spent=timer.seconds_spent(db, ticket.id, now),
        timer_running=timer.open_session(db, ticket.id) is not None,
        allowed_actions=allowed_actions(_actor(actor), _state(ticket)),
    )
```

`backend/app/services/storage.py`:

```python
from dataclasses import dataclass
from typing import Protocol

import boto3
from botocore.config import Config
from botocore.exceptions import ClientError

from app.core.config import Settings

URL_SECONDS = 600


@dataclass(frozen=True)
class StoredObject:
    size_bytes: int
    content_type: str


class Storage(Protocol):
    def presign_put(self, key: str, content_type: str) -> str: ...
    def presign_get(self, key: str) -> str: ...
    def head(self, key: str) -> StoredObject | None: ...


class S3Storage:
    def __init__(self, settings: Settings) -> None:
        self._bucket = settings.s3_bucket_attachments
        self._client = boto3.client(
            "s3",
            endpoint_url=settings.s3_endpoint,
            region_name=settings.s3_region,
            aws_access_key_id=settings.s3_access_key_id,
            aws_secret_access_key=settings.s3_secret_access_key,
            config=Config(
                signature_version="s3v4",
                s3={"addressing_style": "path"},
                # Garage does not accept the newer default checksum headers.
                request_checksum_calculation="when_required",
                response_checksum_validation="when_required",
            ),
        )

    def presign_put(self, key: str, content_type: str) -> str:
        return self._client.generate_presigned_url(
            "put_object",
            Params={"Bucket": self._bucket, "Key": key, "ContentType": content_type},
            ExpiresIn=URL_SECONDS,
        )

    def presign_get(self, key: str) -> str:
        return self._client.generate_presigned_url(
            "get_object", Params={"Bucket": self._bucket, "Key": key}, ExpiresIn=URL_SECONDS
        )

    def head(self, key: str) -> StoredObject | None:
        try:
            response = self._client.head_object(Bucket=self._bucket, Key=key)
        except ClientError as exc:
            if exc.response.get("Error", {}).get("Code") in ("404", "NoSuchKey", "NotFound"):
                return None
            raise
        return StoredObject(
            response["ContentLength"], response.get("ContentType", "application/octet-stream")
        )
```

```python
import re
from pathlib import PurePath
from uuid import uuid4

from sqlalchemy import select
from sqlalchemy.orm import Session

from app.core.errors import Invalid, NotFound
from app.models import Attachment, Ticket, TicketEvent, User
from app.services import tickets
from app.services.storage import Storage

MAX_BYTES = 10 * 1024 * 1024
MAX_FILES = 5
ALLOWED_TYPES = frozenset(
    {
        "image/png",
        "image/jpeg",
        "image/gif",
        "image/webp",
        "application/pdf",
        "application/msword",
        "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
        "application/vnd.ms-excel",
        "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
        "application/vnd.ms-powerpoint",
        "application/vnd.openxmlformats-officedocument.presentationml.presentation",
        "text/plain",
        "text/csv",
    }
)


def _check(content_type: str, size_bytes: int) -> None:
    if content_type not in ALLOWED_TYPES:
        raise Invalid("This file type is not allowed")
    if size_bytes <= 0 or size_bytes > MAX_BYTES:
        raise Invalid("Files must be between 1 byte and 10 MB")


def new_upload(
    storage: Storage, actor: User, file_name: str, content_type: str, size_bytes: int
) -> tuple[str, str]:
    """Return (key, presigned PUT URL) for one file the caller is about to upload."""
    _check(content_type, size_bytes)
    safe_name = re.sub(r"[^A-Za-z0-9._-]", "_", PurePath(file_name).name)[:100]
    if not safe_name.strip("._"):
        raise Invalid("File name is not usable")
    key = f"uploads/{actor.id}/{uuid4().hex}/{safe_name}"
    return key, storage.presign_put(key, content_type)


def attach(
    db: Session,
    storage: Storage,
    actor: User,
    ticket: Ticket,
    keys: list[str],
    event: TicketEvent | None = None,
) -> list[Attachment]:
    if len(keys) > MAX_FILES:
        raise Invalid(f"At most {MAX_FILES} files per ticket or message")
    if len(set(keys)) != len(keys):
        raise Invalid("The same file is listed twice")
    created: list[Attachment] = []
    for key in keys:
        if not key.startswith(f"uploads/{actor.id}/"):
            raise Invalid("Unknown attachment")
        stored = storage.head(key)
        if stored is None:
            raise Invalid("Attachment was not uploaded")
        _check(stored.content_type, stored.size_bytes)
        already = db.execute(
            select(Attachment.id).where(Attachment.storage_key == key)
        ).scalar_one_or_none()
        if already is not None:
            raise Invalid("Attachment is already in use")
        attachment = Attachment(
            ticket_id=ticket.id,
            event_id=None if event is None else event.id,
            storage_key=key,
            file_name=key.rsplit("/", 1)[-1],
            mime_type=stored.content_type,
            size_bytes=stored.size_bytes,
            uploaded_by_id=actor.id,
        )
        db.add(attachment)
        created.append(attachment)
    db.flush()
    return created


def download_url(db: Session, storage: Storage, actor: User, attachment_id: int) -> str:
    attachment = db.get(Attachment, attachment_id)
    if attachment is None:
        raise NotFound("Attachment not found")
    tickets.get_visible_ticket(db, actor, attachment.ticket_id)  # raises NotFound if hidden
    return storage.presign_get(attachment.storage_key)
```

```python
from sqlalchemy import Select, func, select
from sqlalchemy.orm import Session

from app.core.enums import FINAL_STATUSES, EventType, Status
from app.models import Institute, Ticket, TicketEvent, User
from app.schemas.dashboard import Count, DashboardOut


def _counts(db: Session, stmt: Select) -> list[Count]:
    rows = db.execute(stmt).all()
    return sorted(
        (Count(label=str(getattr(label, "value", label)), count=count) for label, count in rows),
        key=lambda row: (-row.count, row.label),
    )


def dashboard(db: Session) -> DashboardOut:
    queued_at = (
        select(TicketEvent.ticket_id, func.min(TicketEvent.created_at).label("queued_at"))
        .where(
            TicketEvent.event_type.in_([EventType.CREATED, EventType.STATUS_CHANGE]),
            TicketEvent.to_value == Status.WAITING_IN_QUEUE.value,
        )
        .group_by(TicketEvent.ticket_id)
        .subquery()
    )
    avg_seconds = db.execute(
        select(func.avg(func.extract("epoch", Ticket.closed_at - queued_at.c.queued_at)))
        .join(queued_at, queued_at.c.ticket_id == Ticket.id)
        .where(Ticket.status == Status.CLOSED)
    ).scalar_one()

    return DashboardOut(
        by_status=_counts(db, select(Ticket.status, func.count()).group_by(Ticket.status)),
        by_ticket_for=_counts(
            db, select(Ticket.ticket_for, func.count()).group_by(Ticket.ticket_for)
        ),
        by_institute=_counts(
            db,
            select(Institute.name, func.count())
            .join(Ticket, Ticket.institute_id == Institute.id)
            .group_by(Institute.id, Institute.name),
        ),
        open_per_developer=_counts(
            db,
            select(User.name, func.count())
            .join(Ticket, Ticket.assignee_id == User.id)
            .where(Ticket.status.not_in(FINAL_STATUSES))
            .group_by(User.id, User.name),
        ),
        avg_hours_queue_to_close=(
            None if avg_seconds is None else round(float(avg_seconds) / 3600, 2)
        ),
    )
```

```python
from sqlalchemy import select
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from app.core.enums import Role
from app.core.errors import Conflict, Invalid, NotFound
from app.core.security import hash_password
from app.models import ApprovalSection, ErpModule, Institute, User
from app.schemas.admin import UserCreate, UserUpdate
from app.services.users import normalise_email

Master = Institute | ApprovalSection | ErpModule
MasterModel = type[Institute] | type[ApprovalSection] | type[ErpModule]


def _flush(db: Session, message: str) -> None:
    try:
        db.flush()
    except IntegrityError as exc:
        raise Conflict(message) from exc


def list_rows(db: Session, model: MasterModel) -> list[Master]:
    return list(db.scalars(select(model).order_by(model.name)))


def create_row(db: Session, model: MasterModel, values: dict) -> Master:
    row = model(**values)
    db.add(row)
    _flush(db, "That name or code is already in use")
    return row


def update_row(db: Session, model: MasterModel, row_id: int, values: dict) -> Master:
    row = db.get(model, row_id)
    if row is None:
        raise NotFound("Not found")
    for field, value in values.items():
        setattr(row, field, value)
    _flush(db, "That name or code is already in use")
    return row


def list_users(db: Session) -> list[User]:
    return list(db.scalars(select(User).order_by(User.name, User.id)))


def _check_refs(db: Session, role: Role, institute_id: int | None, section_id: int | None) -> None:
    if institute_id is not None and db.get(Institute, institute_id) is None:
        raise Invalid("Unknown institute")
    if section_id is not None and db.get(ApprovalSection, section_id) is None:
        raise Invalid("Unknown approval section")
    if role is Role.APPROVER and section_id is None:
        raise Invalid("An approver needs an approval section")


def create_user(db: Session, data: UserCreate) -> User:
    _check_refs(db, data.role, data.institute_id, data.approval_section_id)
    user = User(
        name=data.name,
        email=normalise_email(data.email),
        password_hash=hash_password(data.password),
        role=data.role,
        institute_id=data.institute_id,
        approval_section_id=data.approval_section_id,
        extension=data.extension,
        contact_number=data.contact_number,
    )
    db.add(user)
    _flush(db, "That email is already in use")
    return user


def update_user(db: Session, actor: User, user_id: int, data: UserUpdate) -> User:
    user = db.get(User, user_id)
    if user is None:
        raise NotFound("User not found")
    changes = data.model_dump(exclude_unset=True)
    if user.id == actor.id and (
        changes.get("is_active") is False or changes.get("role", Role.ADMIN) is not Role.ADMIN
    ):
        raise Conflict("You cannot deactivate or demote your own account")
    password = changes.pop("password", None)
    for field, value in changes.items():
        setattr(user, field, value)
    if password:
        user.password_hash = hash_password(password)
    _check_refs(db, user.role, user.institute_id, user.approval_section_id)
    db.flush()
    return user
```

```python
def _person(i: int) -> str:
    return f"{FIRST_NAMES[i % 20]} {LAST_NAMES[(i * 7 + i // 20) % 20]}"


def reset(db: Session) -> None:
    db.execute(
        text(
            "TRUNCATE attachments, work_sessions, ticket_events, tickets, users, "
            "erp_modules, approval_sections, institutes RESTART IDENTITY CASCADE"
        )
    )
    db.execute(text("ALTER SEQUENCE ticket_number_seq RESTART WITH 1"))


def seed(db: Session, password: str, now: datetime) -> dict[str, int]:
    if db.execute(select(func.count()).select_from(User)).scalar_one() > 0:
        raise SystemExit("Database already has users. Use --reset to wipe and reseed.")

    institutes = [Institute(name=name, code=code) for name, code in INSTITUTES]
    sections = [ApprovalSection(name=name) for name in SECTIONS]
    modules = [ErpModule(name=name, url_prefix=ERP_BASE + path) for name, path in MODULES]
    db.add_all([*institutes, *sections, *modules])
    db.flush()
    module_ids = {module.name: module.id for module in modules}

    password_hash = hash_password(password)

    def user(i: int, login: str, role: Role, **fields) -> User:
        return User(
            name=_person(i),
            email=f"{login}@{DOMAIN}",
            password_hash=password_hash,
            role=role,
            **fields,
        )

    admin = user(0, "admin", Role.ADMIN)
    lead = user(1, "lead", Role.LEAD)
    developers = [user(2 + i, f"dev{i + 1}", Role.DEVELOPER) for i in range(4)]
    approvers = [
        user(6 + i, f"approver{i + 1}", Role.APPROVER, approval_section_id=section.id)
        for i, section in enumerate(sections)
    ]
    reporters = [
        user(
            12 + i,
            f"reporter{i + 1}",
            Role.REPORTER,
            institute_id=institute.id,
            extension=str(200 + i),
            contact_number=f"00000{10000 + i}",
        )
        for i, institute in enumerate(institutes)
    ]
    people = [admin, lead, *developers, *approvers, *reporters]
    db.add_all(people)
    db.flush()

    for i in range(TICKET_COUNT):
        created = now - timedelta(days=TICKET_COUNT - i, hours=i % 7)
        ticket_for, ticket_type, module_name, path, description = REQUESTS[i % len(REQUESTS)]
        developer = developers[i % len(developers)]
        base = ERP_BASE if ticket_for is TicketFor.CAMPUS_ERP else SITE_BASE
        values = {
            "ticket_for": ticket_for,
            "ticket_type": ticket_type,
            "erp_module_id": module_ids.get(module_name) if module_name else None,
            "page_url": base + path,
            "description": description,
        }
        if i % 10 == 9:
            tickets.create_ticket(
                db, developer, TicketCreate.model_validate(values), Source.INTERNAL, created
            )
            continue

        section_index = i % len(sections)
        reporter = reporters[i % len(reporters)]
        approver = approvers[section_index]
        values.update(
            approval_section_id=sections[section_index].id,
            contact_number=reporter.contact_number,
            extension=reporter.extension,
        )
        ticket = tickets.create_ticket(
            db, reporter, TicketCreate.model_validate(values), Source.WEB, created
        )

        approve = (30, approver, Action.APPROVE, {"remark": "Approved. Please take this up."})
        assign = (
            90,
            lead,
            Action.ASSIGN,
            {"assignee_id": developer.id, "estimate_minutes": 60 + 30 * (i % 5)},
        )
        start = (240, developer, Action.START, {})
        steps = {
            "pending": [],
            "approved": [approve],
            "assigned": [approve, assign],
            "paused": [approve, assign, start, (300, developer, Action.PAUSE, {})],
            "closed": [
                approve,
                assign,
                start,
                (
                    300 + 20 * (i % 6),
                    developer,
                    Action.CLOSE,
                    {"remark": "Done and verified on the live page."},
                ),
            ],
            "rejected": [
                (45, approver, Action.REJECT, {"remark": "Not in scope for this term."})
            ],
            "clarify": [
                (
                    40,
                    approver,
                    Action.REQUEST_INFO,
                    {
                        "side_status": "clarification_required",
                        "remark": "Which page or report is this about?",
                    },
                )
            ],
            "insufficient": [
                approve,
                assign,
                start,
                (
                    270,
                    developer,
                    Action.REQUEST_INFO,
                    {
                        "side_status": "insufficient_data",
                        "remark": "Please share the list this should apply to.",
                    },
                ),
            ],
        }[SCENARIO_ORDER[i % len(SCENARIO_ORDER)]]
        for minutes, actor, action, body in steps:
            tickets.apply_action(
                db,
                actor,
                ticket.id,
                action,
                ActionBody.model_validate(body),
                created + timedelta(minutes=minutes),
            )

    db.flush()
    return {
        "institutes": len(institutes),
        "sections": len(sections),
        "modules": len(modules),
        "users": len(people),
        "tickets": TICKET_COUNT,
    }
```
